# Arushi Srivastava Portfolio

A static, GitHub Pages-ready portfolio website for Arushi Srivastava, an aspiring Project Manager transitioning from SOX, compliance, and audit into project management and operations.

## Files

- `index.html` - website structure and content
- `styles.css` - responsive corporate visual design
- `script.js` - mobile navigation, scroll reveal, active section state, and contact mailto behavior
- `assets/Arushi_PM_Resume_2026.pdf` - resume linked from the site
- `assets/arushi-profile.jpeg` - profile image used in the hero section

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to `Settings` > `Pages`.
4. Select `Deploy from a branch`.
5. Choose the `main` branch and `/root` folder.
6. Save and wait for GitHub to publish the site URL.
